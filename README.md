# Повітряна мапа України

Desktop-first інтерактивна карта з актуальними тривогами й іншими загрозами по областях та місту Києву.

## Запуск

```powershell
npm.cmd install
copy .env.example .env   # і впишіть свій ключ UkraineAlarm у UKRAINE_ALARM_TOKEN
npm.cmd run dev
```

Відкрийте адресу, яку покаже Vite (типово `http://localhost:5173`). Без ключа локальний proxy віддає помилку, бо джерело не працює без автентифікації. Для production-перевірки виконайте `npm.cmd run build`.

## Як це працює

Дані проходять один шлях: офіційний UkraineAlarm API → нормалізатор `shared/ukraine-alarm-alerts.mjs` → стрічка стану, карта областей, перелік регіонів, сповіщення й CSV. Мапа може живитися двома способами — через локальний proxy (команда вище), через власний backend (`npm.cmd run start:server` або Render) або через статичний знімок, який публікує GitHub Actions (секція про GitHub Pages). Спосіб обирається сам: є `VITE_ALERTS_API_URL` — опитуємо backend, немає — читаємо знімок.

## Дані

Джерелом є офіційний [UkraineAlarm API v3](https://api.ukrainealarm.com/) — `GET /api/v3/alerts` із заголовком `authorization: <ключ>` (без `Bearer`). Ключ тримає серверна сторона (backend або Actions workflow): вона викликає API, розв'язує `regionId` на область за статичним довідником `shared/ukraine-alarm-regions.mjs` і віддає браузеру лише нормалізовані поля — `location`, `region`, `scope`, `type`, `startedAt`, `duration`, `alertLevel`. Типи `AIR`, `ARTILLERY` та `URBAN_FIGHTS` перетворюються на «Повітряна тривога», «Загроза артобстрілу» й «Вуличні бої», рівні — на `red` або `yellow`. Тривога області фарбує область цілком, тривога району чи громади лише позначає її частково.

Джерело віддає один запит на хвилину на ключ, тому backend кешує відповідь на 60 секунд, а до 10 хвилин після помилки чи 429 віддає останній успішний стан. Кеш також захищає ліміт, коли відкрито кілька вкладок.

Без бекенду мапа читає хвилинні знімки `alerts-РРРРММДД-ГГХХ.json` (UTC), які workflow `.github/workflows/alerts-feed.yml` викладає в окрему гілку `feed`. Файл з таким іменем ніколи не переписується, тому п'ятихвилинний кеш `raw.githubusercontent.com` не може видати старі дані під свіжим адресом: клієнт спочатку пробує знімок попередньої хвилини, потім позаминулої, і лише потім — рухомий `alerts.json`. Workflow тримає останні 12 хвилин і публікує цілодобово: один цикл живеться 5 годин і сам запускає наступний, а cron раз на 5 хвилин підхоплює, якщо цикл загинув. У знімку лише нормалізовані публічні поля, токена в ньому немає; читається він прямо з `raw.githubusercontent.com`. Той самий зріз можна створити вручну: `npm.cmd run publish:feed` пише `.feed/alerts-<хвилина>.json` і `.feed/alerts.json`. URL знімка змінюється `VITE_ALERTS_FEED_URL` (порожнє значення не вимикає його — використовується публічний знімок цього репозиторію).

Режими оновлення два, і обидва показують нашу карту, а не чужу. `Автооновлення` (типовий) перевіряє знімок раз на 20 секунд, `Наживо` — раз на 5 секунд; частіше немає сенсу, бо джерело дає новий зріз лише раз на хвилину. Запас свіжості закладений у саме джерело: від появи тривоги до її показу минає приблизно одна хвилина. У `Наживо` стрічка стану показує лише час знімка та позначку `наживо` — лічильник до наступної перевірки там не тикає. Понад 4 хвилини без нового знімка — це збій публікації, і тоді з'являється попередження з кнопкою повтору.

Червоний і жовтий рівні видно на мапі областей, у легенді, переліку регіонів, картці вибраної області, у стрічці стану, журналі змін, CSV-експорті та сповіщеннях. Лічильники `ЧЕРВОНИХ` і `ЖОВТИХ` рахують області з цим рівнем як по всій області, так і в окремих районах. Якщо джерело не передало розпізнаний рівень, регіон показується червоним: недооцінка небезпеки гірша за переоцінку.

Колір області тепер означає тип найважливішої загрози: повітряна тривога лишає червоний і жовтий, артобстріл — світло-коричневий, вуличні бої — синій, хімічна загроза — зелений, радіаційна небезпека — фіолетовий, інша загроза — бірюзовий. Насичений відтінок — червоний рівень, світлий — жовтий. Якщо в області кілька типів, барву бере найспецифічніший (радіація > хімія > вуличні бої > артобстріл > повітряна тривога > інше), а решта загроз лишається в переліку та картці області.

Ключ запитується через форму на [api.ukrainealarm.com](https://api.ukrainealarm.com/) і прив'язаний до акаунта. Тримайте його в локальному `.env` (файл уже в `.gitignore`) та в Actions secret `UKRAINE_ALARM_TOKEN`; якщо розгортаєте backend — ще й у Render Secrets. У код репозиторію й у збірку frontend ключ не потрапляє.

Довідник `shared/ukraine-alarm-regions.mjs` — автозгенерований файл з `npm.cmd run sync:alarm-regions`. Він потрібен, бо `/alerts` називає район чи громаду, але не область, до якої вони належать; окремий запит до `/regions` щохвилини з'їв би весь ліміт. Запускайте синхронізацію, якщо джерело повідомляє про невідомі `regionId`.

Є фільтри повітряних тривог та інших загроз, пошук і фільтри регіонів, обране, журнал змін, дозвільні браузерні сповіщення та CSV-експорт. Сповіщення можна звузити до обраних регіонів і вимкнути сигнал звуку з вібрацією. Налаштування й журнал зберігаються локально у браузері.

Над картою іде стрічка змін останніх хвилин: що й де щойно з'явилось або знялось. Область, чий стан змінився між знімками, на кілька секунд охоплюється пульсуючим кільцем того самого кольору, яким її фарбує тип загрози (бірюзовим — якщо це «відбій»), а в стрічці стану `Автооновлення` тикає лічильник до наступної перевірки. Стовпчики «ГОДИНА» показують, скільки областей тривожилось щохвилини за останню годину; прогалина між стовпчиками означає, що публікація пропала, а не те, що було спокійно.

`npm.cmd run dev` використовує той самий ключ, що й workflow: локальний proxy бере з джерела не більше одного запиту на хвилину, тож одночасно відкриті вкладка мапи та запущений цикл публікації ділять один і той самий ліміт і можуть витиснути одна одну в 429.

Крим і Луганщина — це звичайні області джерела з червоним рівнем, які воно тримає роками (Крим — від 10.12.2022, Луганщина — від 01.11.2026). Мапа фарбує їх червоним нарівні з рештою, включає в лічильники `ЧЕРВОНИХ`, у стрічку стану, сповіщення та журнал змін; окремої «адміністративної» позначки більше немає. Час початку та тривалість відображаються так, як їх надає джерело; ці значення можуть бути приблизними або неузгодженими.

Офіційна карта попереджає, що відображення загроз може бути приблизним і запізнюватися, не охоплює всіх загроз і не призначене для визначення безпеки. Не покладайтеся на цю карту замість офіційних сповіщень: під час тривоги прямуйте в укриття та виконуйте вказівки місцевої влади. Цілі й точні координати в цьому застосунку не показуються.

`npm.cmd run dev` запускає frontend разом із локальним Vite feed proxy. `npm.cmd run start:server` запускає окремий backend на порту 3000. Для production backend використовується `render.yaml`; задайте `ALLOWED_ORIGIN` точним origin GitHub Pages.

## GitHub Pages

1. Створи GitHub repository і push гілку `main`.
2. У GitHub Settings → Pages вибери GitHub Actions як deployment source.
3. У Settings → Secrets and variables → Actions додай repository secret `UKRAINE_ALARM_TOKEN` зі свого ключа UkraineAlarm.
4. Запусти workflow «Publish alerts feed» вручну — він створить гілку `feed` зі знімком поточної хвилини, і далі публікуватиме новий знімок щохвилини цілодобово.

Після цього `.github/workflows/pages.yml` публікує мапу з даними після кожного push у `main`, без жодного зовнішнього хостингу. Зріз джерела відстає приблизно на одну хвилину; час останнього знімка й лічильник до наступної перевірки видно у стрічці стану.

Хочеш свіжіші дані раз на хвилину — розгорни backend: створи у Render Blueprint із цього репозиторію за `render.yaml`, задай `ALLOWED_ORIGIN` як `https://<username>.github.io` і `UKRAINE_ALARM_TOKEN` як Render secret, а URL сервісу скопіюй у GitHub repository variable `ALERTS_API_URL` та перезапусти Pages workflow.

Ключ ніколи не вкладається у збірку frontend — `VITE_`-змінних для нього не існує, а публічний `alerts.json` містить лише нормалізовані дані тривог.

Геометрія областей постачається пакетом `@svg-maps/ukraine`, похідним від [MapSVG](https://mapsvg.com/maps/ukraine), за ліцензією [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Дані тривог надає [UkraineAlarm](https://map.ukrainealarm.com/) — інтерфейс показує видиме посилання на джерело в підвалі та в кнопці джерела.
